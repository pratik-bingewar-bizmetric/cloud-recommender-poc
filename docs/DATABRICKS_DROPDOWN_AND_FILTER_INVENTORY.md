## 1. Executive Summary

This inventory documents every interactive dropdown (`<select>`), date picker (`<input type="date">`), search filter, status filter, pill selector, slider, and modal control across the **Databricks FinOps Command Center** and **Databricks Workspace Explorer**.

All controls have been audited end-to-end to verify:
1. **Bidirectional React State Binding:** Every control has an explicit `value` attribute and an active `onChange` or `onClick` handler.
2. **Dynamic Data Cascading & Reset:** Child selectors and dependent state update automatically when parent scopes change.
3. **API & Ledger Synchronization:** Filtering updates query parameters or transforms displayed data without static mock placeholders.
4. **Resilience & Safe Fallbacks:** Empty, loading, and error states are handled with graceful fallbacks.
